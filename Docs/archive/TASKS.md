## 기록 규칙
- 시작 시 해당 작업을 진행 중으로 변경한다. 검증 실패나 미실행은 완료로 표시하지 않는다.
- 작업 완료 시 변경 파일, 검증 명령/도구와 결과, 남은 한계를 아래 기록에 추가한다.
- 관련 구현과 문서 변경을 함께 커밋한다. 커밋 자체 해시를 같은 커밋에 넣지 말고 `git log`로 확인한다.
- 종료 시 PROGRESS의 다음 행동을 정확히 갱신한다. 세션 시작 시 AGENTS → PROGRESS → TASKS 순으로 확인하고 상세 설계는 필요한 절만 읽는다.
