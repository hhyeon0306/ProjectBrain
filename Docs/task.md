## A2 최소 완료 기준

- 기존 nodes/relations를 읽는 공통 서비스를 사용하며 기존 docs UI와 저장 기준을 구분한다.
- Project/Player와 소수 Feature를 구성하고 관계 종류·방향·출처를 유지한다. 자동 코드 분석으로 표현하지 않는다.
- contains의 허용 계층과 순환 방지·잘못된 참조 표시를 구현하고, 선택 노드에서 부모·관련 자료로 돌아갈 수 있다.
- 실제 설명·코드·이미지를 확인한다. 독립 역할/설계 필드 편집을 넣으려면 데이터 계약을 먼저 정한다.
- 증거가 없으면 미검증으로 표시한다. 실제 컴파일·테스트 Evidence 연결은 A3/V1이며 A2의 완료 선행 조건이 아니다.
- Unity에서 실제 선택·복귀·본문/이미지 표시와 창 크기 변경을 확인한다. 저장소 자체 검사로 UI 확인을 대신하지 않는다.
- 원본 docs 보존과 기존 사용자 변경 보존을 확인한다.

관계 종류 편집을 A2에 포함한다면 같은 서비스를 통해 검증·저장하고 source=v2-migration을 표시한다. 최소 읽기 탐색만 구현하면 편집은 후속 범위로 명시한다.
